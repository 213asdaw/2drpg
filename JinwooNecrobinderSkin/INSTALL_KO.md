# 빠른 설치

## 다운로드

- **설치 ZIP (권장):** https://github.com/213asdaw/2drpg/raw/cursor/jinwoo-necrobinder-skin-b503/releases/JinwooNecrobinderSkin-v1.1.0.zip
- PR: https://github.com/213asdaw/2drpg/pull/25

## 설치 순서

1. 위 ZIP을 받아 압축 해제
2. `mods/JinwooNecrobinderSkin` → `Slay the Spire 2/mods/` 로 복사
3. `mods/CustomCardTextures` → `Slay the Spire 2/mods/` 로 복사
4. [Custom Card Texture Loader](https://www.nexusmods.com/slaythespire2/mods/264) 설치 (카드 일러스트)
5. 게임 실행 → 네크로바인더 = **성진우**, 골골이 = **이그리트**

(선택) 전투 스켈레톤까지 바꾸려면 [Custom Skeleton Loader](https://www.nexusmods.com/slaythespire2/mods/505) + `ReplaceResources/necrobinder`, `ReplaceResources/osty` Spine 파일.
