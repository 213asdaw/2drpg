# 빠른 설치

1. `release/JinwooNecrobinderSkin-v1.0.0.zip` 이 있으면 압축 해제, 없으면 `release/mods/` 사용
2. 안의 `mods/JinwooNecrobinderSkin` → 게임 `mods/` 로 복사
3. 안의 `mods/CustomCardTextures` → 게임 `mods/` 로 복사 (카드 텍스처용)
4. [Custom Card Texture Loader](https://www.nexusmods.com/slaythespire2/mods/264) 설치 (카드 일러스트에 필요)
5. 게임 실행 → 네크로바인더 선택 시 **성진우** 스킨 확인

자세한 내용은 `README.md` 참고.
