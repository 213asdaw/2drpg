# CustomSkeletonLoader — Osty → Igris

Place Spine exports here to replace the Necrobinder companion (Osty) with Igris:

```
ReplaceResources/osty/
  osty.atlas
  osty.skel
  osty.png
```

Copy this folder into your CustomSkeletonLoader `ReplaceResources/` directory.
Filenames must match vanilla Osty skeleton ids (often `osty`).

Until Spine files are provided, localization still renames Osty → 이그리트 / Igris in UI text.
