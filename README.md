# 2drpg

Unity 2D RPG 저장소입니다.

## 싱크플랜 (설치해서 열기)

싱크대 도면 → 3D 미리보기 앱은 브랜치 `cursor/sink-blueprint-3d-407f` / `sink-plan-3d/` 에 있습니다.

### Windows
`SinkPlan-1.0.0-portable.exe` 더블클릭 (설치 불필요)

패키지 다시 만들기:
```bash
cd sink-plan-3d
npm install
npm run dist:win
```
결과: `sink-plan-3d/release-build/SinkPlan-1.0.0-portable.exe`

자세한 설명: [`sink-plan-3d/README.md`](sink-plan-3d/README.md)
