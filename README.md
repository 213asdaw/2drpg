# 2D Fighting Game

Unity **2022.3.62f1 (LTS)** 로 만든 **2인용 2D 격투 게임** 프로토타입입니다.

빈 씬에서 **Play** 만 누르면 `FightingGame` 이 런타임에 카메라, 무대, 캐릭터, HUD 를 자동으로 생성합니다.

## 게임 규칙

- **2인 로컬 대전** (같은 키보드)
- **3선승제** (2라운드 선승 시 매치 승리)
- 라운드당 **99초** 제한 시간
- HP 가 0 이 되면 **KO**
- 시간 종료 시 **HP 가 더 많은 쪽** 승리 (동점이면 무승부)
- **가드(S / ↓)** 시 받는 피해 75% 감소

## 조작법

| 동작 | 1P (파란색) | 2P (빨간색) |
|------|-------------|-------------|
| 이동 | `A` / `D` | `←` / `→` |
| 점프 | `W` | `↑` |
| 가드 | `S` (땅에 있을 때) | `↓` (땅에 있을 때) |
| 약공격 | `J` | `1` |
| 킥 | `K` | `2` |
| 강공격 | `L` | `3` |
| 재대결 | `R` (매치 종료 후) | `R` |

## 공격 특성

| 공격 | 피해 | 속도 | 비고 |
|------|------|------|------|
| 약공 (J / 1) | 8 | 빠름 | 안정적인 견제 |
| 킥 (K / 2) | 12 | 보통 | 중거리 |
| 강공 (L / 3) | 20 | 느림 | 높은 피해, 긴 후딜 |

## 프로젝트 구조

```
Assets/Scripts/FightingGame/
  FightingGame.cs       # 부트스트랩, 무대/HUD, 매치 흐름
  FighterController.cs # 이동, 점프, 공격, 가드, 히트 판정
  MatchManager.cs     # 라운드/타이머/승패
  FighterInput.cs     # 1P/2P 입력
  ProceduralArt.cs    # 런타임 스프라이트 생성
  FightConstants.cs   # 밸런스 상수
```

## Unity 에서 실행

1. Unity Hub 에서 **2022.3.62f1** 로 이 폴더를 프로젝트로 엽니다.
2. 아무 씬이나 열거나 빈 씬을 만든 뒤 **Play** 를 누릅니다.
3. 첫 실행 시 `Library/` 패키지 복원으로 시간이 조금 걸릴 수 있습니다.
