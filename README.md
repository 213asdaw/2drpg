# 2D Fighting Game

Unity **2022.3.62f1 (LTS)** 로 만든 **2D 격투 게임** 프로토타입입니다.

빈 씬에서 **Play** 를 누르면 메인 메뉴가 뜨고, **오프라인(로컬 2P)** 또는 **온라인 대전**을 선택할 수 있습니다.

## 게임 규칙

- **2인 대전** (오프라인: 같은 PC / 온라인: 호스트 + 클라이언트)
- **3선승제** (2라운드 선승 시 매치 승리)
- 라운드당 **99초** 제한 시간
- HP 가 0 이 되면 **KO**
- 시간 종료 시 **HP 가 더 많은 쪽** 승리 (동점이면 무승부)
- **가드(S / ↓)** 시 받는 피해 75% 감소

## 플레이 방법

### 1. 메인 메뉴

Play 후 다음 중 선택:

| 메뉴 | 설명 |
|------|------|
| **오프라인 (로컬 2P)** | 한 키보드로 2명이 붙는 기존 방식 |
| **온라인 — 호스트 만들기** | 방을 만들고 상대 접속 대기 |
| **온라인 — IP로 접속** | 호스트 IP 입력 후 접속 |

### 2. 온라인 대전 (LAN)

1. **플레이어 A**: `온라인 — 호스트 만들기` 클릭
2. **플레이어 B**: A의 IP 주소 입력 (예: `192.168.0.10`) 후 `온라인 — IP로 접속`
3. 기본 포트: **7777**
4. 두 명이 접속되면 자동으로 매치 시작

> 같은 Wi‑Fi / LAN 에서 테스트하는 것을 권장합니다. 인터넷 네트워크는 방화벽/포트 포워딩 설정이 필요할 수 있습니다.

### 3. 온라인 조작 (각자 자신의 PC)

| 동작 | 키 |
|------|-----|
| 이동 | `A` / `D` |
| 점프 | `W` |
| 가드 | `S` |
| 약공격 | `J` |
| 킥 | `K` |
| 강공격 | `L` |
| 재대결 | `R` (매치 종료 후, **호스트만**) |

## 공격 특성

| 공격 | 피해 | 속도 | 비고 |
|------|------|------|------|
| 약공 | 8 | 빠름 | 안정적인 견제 |
| 킥 | 12 | 보통 | 중거리 |
| 강공 | 20 | 느림 | 높은 피해, 긴 후딜 |

## 온라인 아키텍처

- **Unity Netcode for GameObjects** (호스트/클라이언트)
- **서버 권한(Authoritative)**: 호스트가 전투 판정 및 HP 계산
- 클라이언트는 입력 전송 → 서버 시뮬레이션 → 상태 동기화
- 최대 **2명** 접속 (3번째 접속 거부)

## 프로젝트 구조

```
Assets/Scripts/FightingGame/
  GameLauncher.cs              # 메인 메뉴, 모드 선택
  FightingGame.cs              # 오프라인 매치
  OnlineFightingGame.cs        # 온라인 HUD/세션
  NetworkFighter.cs            # 네트워크 캐릭터
  NetworkMatchCoordinator.cs   # 온라인 라운드/매치 관리
  FightingNetworkBootstrap.cs  # NetworkManager 런타임 설정
  FighterController.cs         # 전투 로직
  ...
```

## Unity 에서 실행

1. Unity Hub 에서 **2022.3.62f1** 로 이 폴더를 프로젝트로 엽니다.
2. 아무 씬이나 열거나 빈 씬을 만든 뒤 **Play** 를 누릅니다.
3. 첫 실행 시 `Library/` 패키지 복원(Netcode 포함)으로 시간이 조금 걸릴 수 있습니다.

## 확장 아이디어

- Relay / Lobby 서비스 (Unity Relay, Steam, Photon)로 IP 없이 매칭
- 롤백 넷코드로 입력 지연 체감 개선
- 애니메이터/스프라이트 시트, 콤보, 필살기
- AI 상대, 캐릭터 선택 화면
