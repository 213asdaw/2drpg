# untitled (slash) — 불꽃의 검 / 검기 플러그인

## 변경 (원본 JAR 기준 수정)

- **FLINT custom_model_data: 1001** (리소스팩 검기 이펙트 유지)
- **SWEEP_ATTACK(휘두르기) 파티클 제거**
- 검기 아머스탠드 **우클릭 시 아이템 교체 차단** + 손 FLINT 자동 복구

## 서버 적용

```
money서버시즌1/untitled-1.0-SNAPSHOT.jar  ← 이 파일로 교체
또는 plugins/untitled-1.0-SNAPSHOT.jar
서버 재시작
```

빌드 결과: `untitled/target/untitled-1.0-SNAPSHOT.jar`  
배포 복사본: `releases/untitled-1.0-SNAPSHOT.jar`

## 스킬

| 입력 | 효과 |
|------|------|
| **불꽃의 검** 우클릭 | 불꽃의 검기 |
| **웅크린 채** 우클릭 | 불꽃 방패 (10초) |
