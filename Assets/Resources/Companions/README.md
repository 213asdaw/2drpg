# Companion Sprite Replacement Guide

이 폴더의 PNG 파일을 같은 이름으로 교체하면 게임 안 동료 이미지가 바뀝니다.

## 권장 규격

- PNG 투명 배경
- 128x192 이상
- 도트 픽셀아트라면 nearest/point 필터에 맞는 선명한 이미지
- 대기 포즈 1장부터 시작 가능

## 상용 수집형 RPG 수준으로 올리려면

캐릭터별로 아래 자료가 있으면 가장 좋습니다.

- 대기/공격/피격/스킬 스프라이트 시트
- 원화 또는 PSD
- 원하는 레퍼런스 이미지
- 캐릭터별 무기, 속성, 성격 설정
